# 🔑 ADD YOUR RAZORPAY KEY - SUPER SIMPLE!

## ✅ **DO THIS NOW (30 SECONDS):**

### **Step 1: Open the File**
Open: `src/services/razorpayService.ts`

### **Step 2: Find Line 5**
You'll see:
```typescript
const RAZORPAY_KEY_ID = 'YOUR_RAZORPAY_KEY_HERE';
```

### **Step 3: Replace with Your Key**
Change it to:
```typescript
const RAZORPAY_KEY_ID = 'rzp_live_YOUR_ACTUAL_KEY';
```

**Example:**
```typescript

```

### **Step 4: Save File**
Press `Cmd + S` (Mac) or `Ctrl + S` (Windows)

### **Step 5: Refresh Browser**
Press `Cmd + R` (Mac) or `Ctrl + R` (Windows)
